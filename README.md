# ReliableChange

Implementation of **Reliability-Aware Missing-Modality SAR-Optical Change Detection for Rapid Disaster Damage Mapping**.

## Installation

Python >=3.10.

```bash
python -m pip install -e .
```

## Data and preprocessing

Generate synthetic seven-channel images, masks and availability/quality arrays. These are generated image controls, not SAR measurements.

```bash
reliable-change demo --output data/generated.npz --count 96 --config config.json --seed 13
reliable-change prepare --input data/generated.npz --output data/prepared
```

`x[N,7,H,W]`: pre RGB, post RGB and post SAR; `y[N,1,H,W]`: change mask; `available[N,2]`: post optical/SAR availability (at least one present). Optional `quality[N,2,H,W]` holds known corruption quality.

Numeric NPZ input uses `group` to keep related samples together. `prepare` writes train/validation/calibration/test archives from ordered groups (60/15/10/15), or honors explicit `split` codes 0/1/2/3.

## Training and inference

```bash
reliable-change train --input data/prepared --output runs/full --config config.json --variant full --epochs 100 --batch-size 16 --seed 13
```

Use `--device cuda` to select CUDA; CPU is the default. Keep the configuration, splits and seed fixed across comparisons.

## Evaluation

```bash
reliable-change evaluate --input data/prepared/test.npz --model runs/full/model.pt --output runs/full/evaluation
```

## Ablations

Variants: `full`, `baseline`, `no_alignment`, `no_quality`, `no_mask_consistency`, `no_boundary`, `no_change`. Reuse the prepared data and training seed:

```bash
reliable-change train --input data/prepared --output runs/baseline --config config.json --variant baseline --epochs 100 --batch-size 16 --seed 13
reliable-change evaluate --input data/prepared/test.npz --model runs/baseline/model.pt --output runs/baseline/evaluation
```

## Outputs

- `data/prepared/*.npz`: grouped data splits.
- `runs/full/model.pt`: validation-selected parameters and model configuration.
- `runs/full/history.json` and `training.json`: objectives and run settings.
- `runs/full/evaluation/predictions.npz` and `metrics.json`: predictions/mechanism arrays and computed metrics.

```bash
reliable-change plot --input runs --output runs/figures
```

`runs/figures/*.png` compares saved evaluation metrics. All data, checkpoint and output paths are CLI arguments.

## Architecture and metrics

The model uses separate optical/SAR stems and a shared four-stage encoder (64/128/256/512 at strides 4/8/16/32), local reflected correlation alignment (input bound 4, radii 1/0/0/0, temperature .1), masked relative weights times absolute confidence, confidence-aware U decoding, and region/boundary heads. Training samples full/missing-optical/missing-SAR with probabilities .5/.25/.25 for complete triplets. Full-input detached teachers supervise random single-modality students with Bernoulli KL only on originally complete observations. Evaluation executes one pass, without masking or a teacher.

| Module / endpoint | Entry | Command |
|---|---|---|
| Event folds and training-only optical/SAR preprocessing | `reliable_change.prepare_bright` | `python -m reliable_change.prepare_bright --input data/bright_triplets.npz --output data/fold0 --fold 0` |
| Availability/alignment/reliability and five weighted objectives | `Model.forward/objective` | `python -m reliable_change.cli train --input data/fold0 --config config.json --output runs/full --epochs 120 --batch-size 8 --lr 0.00006 --seed 13` |
| Region/boundary maps and pooled diagnostics | `cli evaluate` | `python -m reliable_change.cli evaluate --input data/fold0/test.npz --model runs/full/model.pt --output runs/full/evaluation` |
| Unlabeled deployment (x and available only) | `cli infer` | `python -m reliable_change.cli infer --input data/unlabeled.npz --model runs/full/model.pt --output runs/full/inference` |
| Event-macro P/R/F1/IoU/BF1, worst mode and acquisition drops | `evaluate_modes` | `python -m reliable_change.evaluate_modes --input data/fold0/test.npz --model runs/full/model.pt --output runs/full/modes.json` |

Obtain [BRIGHT](https://github.com/ChenHongruixuan/BRIGHT) from its maintainers. Provide `x[N,7,H,W]` calibrated, nonnegative linear-intensity SAR plus optical data on the same projected grid, binary `y` damaged-building labels, `available`, `event` (Bata/Beirut/Hawaii/Libya/Noto), and globally unique `group` IDs per source image. Optional `quality[N,2,H,W]` contains known corruption targets. Folds use cyclic test/validation events and remaining three training events. The 1st/99th optical percentiles and log1p-SAR clipping/mean/std are fitted on acquired training observations only, applied to every split and saved in `preprocessing.json`. Provider access, calibrated input products and geospatial coregistration are prerequisites, not generated by the synthetic demo.

Loss weights are region WBCE+Lovasz plus .3 change margin (L1 reference/post embeddings, margin1), .2 KL, .1 multiscale quality, and .2 boundary BCE (3x3 morphological gradient). Positive WBCE weight is fitted once from training mask counts. AdamW, weight decay .01, five-epoch warm-up/cosine, 512 random crops, flips/right-angle rotations/optical brightness .9–1.1, and validation-F1 checkpoint selection are implemented. `widths` can be reduced only for functional checks. Variants additionally include `no_boundary` and `no_change`; each trains separately with `--variant`, without changing held-out groups or labels.

## Tiled inference and comparisons

The encoder uses convolutional blocks, GroupNorm and shared projections. Inputs must be matched projected source tiles. Evaluation and unlabeled inference use reflected 512-pixel tiles with 64-pixel halos, stitching 384-pixel interiors. `--tile-size` and `--halo` configure this path. Use `prepare_bright` for event-based preparation; generic `demo/prepare` provides generated image inputs. Generic `mean_latency_ms` includes batched host evaluation.

### Controlled stress, statistics and concrete baselines

`reliable_change.protocol` implements deterministic, label-independent cloud cover (training optical mean fill, or supplied cloud masks), Gamma speckle in the original SAR intensity domain, and reflected optical/SAR displacement. It preserves missing-modality flags and uses saved training preprocessing. Generate each severity before running the same frozen model:

```bash
python -m reliable_change.protocol stress --input data/fold0/test.npz --preprocessing data/fold0/preprocessing.json --kind cloud --levels 0.25 --output data/stress
python -m reliable_change.cli evaluate --input data/stress/cloud_0.25.npz --model runs/full/model.pt --output runs/full/cloud025
python -m reliable_change.protocol statistics --input data/event_seed_metrics.csv --metric f1 --reference full --output runs/paired_statistics.json
```

The statistics CSV has `method,event,seed` and metric columns. Seeds are averaged within each held-out event before paired event bootstrap, exact sign-flip testing for small event counts, and Holm correction. This avoids treating five seeds of the same event as independent events.

The shared trainer accepts `architecture=unet|changeformer|changemamba` in the configuration. U-Net is a trainable four-level early-fusion baseline over seven observations plus two availability planes. ChangeFormer imports the actual [official V6 encoder and decoder](https://github.com/wgcban/ChangeFormer), adapts its two input projections to nine channels and trains all deep-supervision outputs with the same region loss. The two temporal streams carry pre-optical and post-optical/SAR respectively, with unavailable channels zeroed. Both baselines use the same missingness sampling, optimizer, augmentation, validation selection, halo inference and metrics as the main method.

```bash
git clone https://github.com/wgcban/ChangeFormer third_party/ChangeFormer
python -m reliable_change.cli train --input data/fold0 --config config.json --set 'architecture="changeformer"' --set 'changeformer_root="third_party/ChangeFormer"' --output runs/changeformer --epochs 120 --batch-size 8
python baseline_check.py --changeformer-root third_party/ChangeFormer
```

ChangeMamba imports the official `ChangeMambaBCD` blocks and decoder from [MambaCD](https://github.com/ChenHongruixuan/MambaCD). Set `architecture="changemamba"`, `changemamba_root`, and `changemamba_backend="reference"` to execute the actual selective recurrence in differentiable PyTorch without compiled extensions. This keeps the official v3noz architecture, cross scan/merge, learned state parameters and decoder. `native` retains the author kernels and requires their extensions. The two backends use separate processes; use native kernels for CUDA throughput measurements. Install optional author imports with `pip install -e '.[baselines]'`.

`architecture="fc_siam_diff"|"fc_siam_conc"` imports the original [FC-Siam](https://github.com/rcdaudt/fully_convolutional_change_detection) network using `fc_siam_root`. Only its input width changes to the same nine observed/availability channels; skip differences/concatenation, dropout, transposed convolutions and log-softmax remain the author implementation.

`architecture="glcd_da_cd"` and `glcd_da_root` select the [GLCD-DA detection network](https://github.com/WHU-SGG-RS-Pro-Group/ChangeDetection-GLCD-DA): pretrained ResNet18, Laplacian pyramid, MDPM/RCSA, transformer, fusion and three supervised outputs. A learned shared 9-to-3 projection supplies RGB to its edge path. Gaussian kernels follow the input device; same-named upstream `models` packages are isolated during import. Supply inputs already prepared for the CD stage.

```bash
python scan_siam_check.py --fc-siam-root third_party/FC-Siam --changemamba-root third_party/MambaCD --glcd-da-root third_party/GLCD-DA
```
